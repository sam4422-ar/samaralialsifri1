# Prompt Library User Guide

## How to Use a Template

1. Select the template that matches the customer's request.
2. Read its purpose and instructions.
3. Fill in all required variables, such as `[CUSTOMER_MESSAGE]`, `[LANGUAGE]`, `[TONE]`, and `[FACTS]`.
4. Include only the information needed for the task.
5. Run the prompt.
6. Check the output against the safety rules and quality checklist.
7. Ask a human reviewer to verify payment, contract, legal, or sensitive privacy issues when necessary.
8. Save the test output and screenshot for documentation.

## Template Selection

- `CS-Reply-Inquiry`: General customer inquiries.
- `CS-Reply-Complaint`: Customer dissatisfaction or complaints.
- `CS-Classify-Request`: Identifying the type of request.
- `CS-Privacy-Mask`: Removing personal information before sharing.
- `CS-Escalate-Issue`: Determining whether a matter requires referral.

## Variable Guidelines

Replace every required placeholder with the actual task information. Do not leave sample customer details in a real response. If information is unavailable, state that it needs confirmation instead of inventing it.

## Human Review

Human review is particularly important for payments, contracts, legal matters, privacy risks, and any unverified company information.

## Limitations

These templates generate text recommendations only. They do not verify transactions, book appointments, contact departments, approve refunds, or perform actual escalation.
